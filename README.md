# Retail-Discount-Engine

A business-focused retail pricing and inventory management project designed to simulate dynamic discount calculations, inventory updates, and product tracking using JavaScript and front-end web technologies.

---

## Technologies Used
- JavaScript  
- HTML  
- CSS  

---

## Features
- Dynamic discount calculations  
- Product pricing management  
- Inventory tracking functionality  
- Retail business logic simulation  
- Product information updates  

---

## Skills Demonstrated
- JavaScript Fundamentals  
- Business Logic Development  
- Problem-Solving  
- Inventory Management Concepts  
- Front-End Development  

---

## Project Purpose
This project was created to practice building retail-focused business applications involving pricing calculations, inventory management, and operational workflow logic using JavaScript and web technologies.
